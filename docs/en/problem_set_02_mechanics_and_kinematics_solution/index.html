1.1 Deriving Velocity & Acceleration

We start from the general equation of motion:

x(t) = x₀ + v₀·t + ½·a·t²
Velocity v(t):

Velocity is the first derivative of position. We differentiate x(t):

v(t) = dx/dt = v₀ + a·t
Acceleration a(t):

Acceleration is the second derivative of position:

a(t) = dv/dt = d²x/dt² = a = const
// constant — does not depend on time!

Problem 2 — Derivation & Interactive Simulation

2.1 Derivation of Equations

Decompose initial velocity:
v₀ₓ = v₀·cos(α)    v₀ᵧ = v₀·sin(α)
Horizontal (no force):
x(t) = v₀·cos(α)·t
Vertical (gravity):
y(t) = v₀·sin(α)·t − ½·g·t²

2.2 Key Formulas

T = 2·v₀·sin(α) / g   // flight time
H = v₀²·sin²(α) / (2g)   // max height
R = v₀²·sin(2α) / g   // range — max at α=45°

Maximum range: sin(2α) = 1 → α = 45°
